# «Ритм» — открытые исходники

«Ритм» — приложение для iPhone на русском языке: сон, восстановление и нагрузка по браслету WHOOP (4.0, 5.0, MG) и Apple Watch, команды друзей с рейтингом, лентой и чатом. Все показатели считаются на телефоне.

Это форк [OpenStrap Edge](https://github.com/OpenStrap/edge) и распространяется по той же лицензии — **GNU AGPL-3.0** (файл `LICENSE`). Изменения «Ритма» лежат в основном в `lib/ritm/`, `server/` (сервер сообщества) и `ios/Runner/` (Apple Health, Sign in with Apple, уведомления).

## Что здесь
- `lib/ritm/` — экраны и расчёты «Ритма»: три кольца (Восстановление, Сон, Нагрузка), оценка сна, потребность и долг сна, сверка с экспортом WHOOP, биовозраст, «Сообщество» и чат.
- `server/` — сервер сообщества: FastAPI + PostgreSQL. Хранит только итоги дня (оценка сна %, восстановление %, нагрузка), команды, реакции и сообщения чата. Пульс, ВСР, ЭКГ, стресс и биовозраст на сервер не уходят — проверка `tests/test_api.py::test_schema_has_no_vitals`.
- `tool/ritm_b5_e2e.sh` — проверка сервера целиком на локальной копии (два аккаунта, рейтинг, удаление, чат по WebSocket).

## Чего здесь нет
- Личной выгрузки WHOOP, на которой подбирались коэффициенты: тесты «Dart = Python на данных WHOOP» без неё пропускаются. Подобранные коэффициенты — в коде (`ritm_rings.dart`, `ritm_sleep.dart`).
- Ключей: JWT-секрет сервера и ключ уведомлений Apple (.p8) задаются только на сервере (`server/deploy/install.sh`).
- Истории коммитов: публикуется чистый снимок, потому что в рабочей истории есть личные данные.

## Сборка
Flutter 3.x, Xcode 16+: `flutter pub get && flutter build ios`. Сервер: `pip install -r server/requirements.txt`, база PostgreSQL 16+, переменные `RITM_DB_DSN`, `RITM_JWT_SECRET` (≥ 32 символа). Тесты сервера: `RITM_TEST_DSN=… pytest server/tests`.

«Ритм» — не медицинское изделие. Показатели — для самонаблюдения, не для диагностики.
