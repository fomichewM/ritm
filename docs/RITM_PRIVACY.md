# «Ритм» — политика конфиденциальности

Редакция от 22.11.2026. Относится к приложению «Ритм» для iPhone (com.oporagroup.ritm), которое раздаётся через TestFlight.

## Главное
- Всё, что «Ритм» получает от браслета WHOOP, Apple Watch и приложения «Здоровье», хранится **только на вашем телефоне**: пульс, ВСР, ЭКГ, сон по стадиям, стресс, биовозраст, тренировки, импортированная выгрузка WHOOP.
- Без входа в «Сообщество» и без ключа Помощника ваши показатели никуда не отправляются (исключения по вашему действию — ниже).
- Рекламы и продажи данных нет. Третьим лицам данные уходят только по вашему действию (пункты 2, 4, 5 ниже).

## Что уходит с телефона и только по вашему действию
1. **Сообщество (по желанию).** Если вы входите через Apple и даёте согласие, на сервер «Ритма» (Россия) уходят: идентификатор Apple (без почты), имя из профиля «Ритма», по желанию фото; итоги дня — оценка сна %, восстановление %, нагрузка за день и неделю, по желанию тренировки (тип, минуты, нагрузка); ваши реакции и сообщения чата команды; токен телефона для уведомлений; версия, время и IP-адрес согласия. Зачем — показывать рейтинг, ленту и чат участникам ваших команд. Хранится, пока есть аккаунт; «Удалить аккаунт» стирает данные сразу, из резервных копий — в течение 14 дней.
2. **Помощник (ИИ, по желанию).** Работает только с ВАШИМ ключом OpenAI (или вашим сервером), который вы сами вводите в настройках; ключ хранится в связке ключей iPhone. Запросы идут с телефона напрямую в OpenAI, не через сервер «Ритма»: ваш вопрос и нужные показатели (сон, восстановление, нагрузка, пульс покоя, ВСР, тренировки). Посекундные записи браслета не отправляются. Обработку в OpenAI регулируют условия OpenAI: https://openai.com/policies/
3. **Отчёты о сбоях и «данные для исследований»** — выключены по умолчанию, включаются только вами в настройках конфиденциальности.
4. **«Сообщить о проблеме»** (в разделе «О приложении») — экран из исходного проекта OpenStrap Edge: по вашему нажатию «Отправить» архив диагностики (список файлов показан на экране) уходит разработчикам OpenStrap (reports.openstrap.site), а не автору «Ритма». О проблемах «Ритма» лучше писать на почту ниже.
5. **Карта маршрута тренировки** загружает фрагменты карты с OpenStreetMap (их сервер видит район карты). **Поиск продукта по штрихкоду** спрашивает openfoodfacts.org только о самом штрихкоде.

## Ваши права
Узнать, исправить, скрыть (переключатели публикации в «Сообществе»), удалить («Удалить аккаунт» или удаление приложения — локальные данные стираются вместе с ним), отозвать согласие.

## Не медицинское изделие
«Ритм» показывает оценки для самонаблюдения. Это не диагноз и не замена врачу.
