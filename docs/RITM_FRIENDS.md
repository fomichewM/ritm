# «Ритм» — инструкция для друзей

«Ритм» показывает сон, восстановление и нагрузку по браслету WHOOP прямо на iPhone, по-русски, без подписки. Можно соревноваться с друзьями в командах.

## 1. Установка
1. Ссылку на установку присылает Михаил (закрытая раздача друзьям). Нужен iPhone с актуальной iOS.
2. Откройте «Ритм». Три первых экрана: браслет → «Здоровье» → Помощник (необязательно).

## 2. Какой у вас набор устройств

| Набор | Что делать | Что будет |
|---|---|---|
| WHOOP 5.0 или MG + Apple Watch | Браслет носите всегда, часы — днём. **Ночью часы не нужны.** | Ночь (сон, пульс покоя, ВСР, восстановление) — с браслета; тренировки, шаги и пульс на беге — с часов, если они точнее. ЭКГ — у MG и часов. SpO₂ — только если спите в часах. |
| Только WHOOP 5.0 / MG | Носите браслет постоянно, ночью обязательно. | Всё считается по браслету. |
| Только WHOOP 4.0 | То же. | Всё, кроме ЭКГ. |
| WHOOP 4.0 + Garmin | Garmin Connect → «Здоровье» (тренировки) и трансляция пульса на тренировке. | Ночь — браслет, тренировки — из Garmin. |

Подключение: **Ещё → Браслет** (или кнопка «Найти браслет» на первом экране). Браслет должен быть рядом и заряжен. Если браслет подключён к приложению WHOOP на этом же телефоне, закройте приложение WHOOP.

## 3. Прошивка — не обновлять
**Не обновляйте прошивку браслета в приложении WHOOP**, пока пользуетесь «Ритмом». Новая прошивка может изменить способ передачи данных, и «Ритм» перестанет их читать. Если обновление уже прошло и данные не идут — напишите Михаилу (Ещё → О приложении → Сообщить о проблеме).

## 4. «Здоровье» (Apple Health)
Разрешите доступ на первом запуске или позже: **Ещё → Источники и сверка**. «Ритм» читает шаги, тренировки и данные Apple Watch и записывает туда сон. Пульс и ВСР браслета остаются в «Ритме».

## 5. Первые дни
- Восстановление считается от вашей нормы. Первые 4 ночи идёт калибровка — числа ещё нет; с 5-й по 14-ю ночь оно помечено «предварительно».
- Монитор стресса первые 14 дней калибруется (на главной — «калибровка N/14»).
- Стадии сна — **оценка** по браслету (как и у WHOOP), не медицинское измерение.
- «Ритм» — не медицинское изделие.

## 6. Сверка с WHOOP (по желанию)
Если у вас была подписка WHOOP, можно сравнить числа:
1. В приложении WHOOP: профиль → настройки приложения → **экспорт данных** (Data Export). WHOOP пришлёт архив CSV на почту.
2. В «Ритме»: **Ещё → Данные → Импорт CSV WHOOP**, выберите файлы из архива.
3. **Ещё → Источники и сверка → Сверка с WHOOP** покажет по дням, где «Ритм» и WHOOP расходятся больше допуска (зелёный — в допуске, красный — нет). Сверка идёт только по дням, которые есть и там, и там.

## 7. Сообщество, команды, чат
- Вкладка **Сообщество → Войти через Apple** → согласие (две галочки).
- Команда: **⋯ → Создать команду** или **Войти по коду** (6 знаков от друга).
- На сервер уходят **только** итоги дня — оценка сна %, восстановление %, нагрузка за день и неделю, по желанию — тренировки (тип, минуты, нагрузка) и фото — плюс ваши сообщения в чате команды. Пульс, ВСР, ЭКГ, стресс и биовозраст не уходят никогда. Что показывать, выбираете в **Сообщество → ⚙**.
- Уведомление о новом сообщении приходит, когда чат закрыт; в нём только название команды. Выключить для одной команды: команда → **⋯ → Уведомления о сообщениях**.
- Удалить своё сообщение — значок корзины рядом с ним. Удалить аккаунт целиком — **Сообщество → ⚙ → Удалить аккаунт** (с сервера сразу, из резервных копий — до 14 дней).

## 8. Помощник и свой ключ OpenAI (необязательно)
- Без ключа работает всё, кроме ответов Помощника.
- Ключ создаётся на platform.openai.com (оплата по факту запросов — ваша). Вставьте его: круглая кнопка Помощника справа от вкладок → «Указать ключ». Ключ хранится в связке ключей iPhone и уходит только в OpenAI — не на сервер «Ритма».
- **Что отправляется в OpenAI:** ваш вопрос и показатели, которые Помощник запросит из базы на телефоне (сон, восстановление, нагрузка, пульс покоя, ВСР, тренировки). Посекундные записи браслета не отправляются.
- OpenAI по умолчанию не использует данные, пришедшие через API, для обучения моделей (условия OpenAI для API: https://platform.openai.com/docs/guides/your-data). Это условия OpenAI, а не «Ритма»; данные обрабатываются в США.
